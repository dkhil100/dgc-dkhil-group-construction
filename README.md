# DGC DKHIL GROUP CONSTRUCTION Website

A modern Next.js 14 web application built with Tailwind CSS, Framer Motion, and Lucide Icons.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
